# TITLE: 尝试 — 失败与成功登录
# STEP: 3
# MINUTES: 8

### WHY

了解攻击者如何尝试破解密码，能帮助你更好地理解防御策略。

攻击者通常使用自动化工具（如 Hydra、Medusa）以每秒数百次的速度尝试常见密码组合。密码强度测试的关键指标：
- 密码长度（推荐 ≥12 字符）
- 字符多样性（大写+小写+数字+符号）
- 是否在常见密码字典中

### DO

1. 尝试一次**失败**的登录：
```
ssh student@127.0.0.1 -p 2222
```
输入错误密码（如 `wrongpassword`）

2. 尝试一次**成功**的登录：
```
ssh student@127.0.0.1 -p 2222
```
输入正确密码 `Student123`

3. 尝试 SSH 连接但指定不存在的用户：
```
ssh admin@127.0.0.1 -p 2222
```

### CHECK

- 记录了失败登录的错误信息吗？
- 三次尝试的结果分别是什么？
