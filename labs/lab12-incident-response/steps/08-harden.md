# TITLE: 加固 — 长期安全改进
# STEP: 8
# MINUTES: 12

### WHY

遏制是止血，加固是治本。基于本次事件的教训，提出长期改进措施。

**加固措施**：
1. **密码策略**：强制强密码、禁用默认账户、定期轮换
2. **SSH 加固**：密钥认证、fail2ban、禁止 root 登录
3. **Web 服务器**：关闭目录浏览、禁止访问 `/backup/`
4. **应用安全**：修复硬编码凭证、添加认证和授权
5. **监控**：增加日志记录、设置告警规则
6. **流程**：建立定期安全审计机制

### DO

在报告中列出至少 5 条长期加固建议，每条包含：
- 问题描述
- 具体措施
- 优先级（高/中/低）
- 责任人建议
