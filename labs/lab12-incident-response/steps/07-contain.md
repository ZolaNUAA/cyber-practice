# TITLE: 遏制 — 短期止血方案
# STEP: 7
# MINUTES: 10

### WHY

遏制（Containment）的目标是**阻止进一步的损害**，同时保留证据。

**遏制措施**：
1. 立即禁用被入侵的账户
2. 隔离受影响系统
3. 阻止攻击者的 IP
4. 保存当前状态用于取证
5. 通知相关方

**短期 vs 长期**：
- 短期（本步骤）：止血
- 长期（下一步）：根除

### DO

制定遏制方案：

1. **立即行动**：
   - 修改 student 密码
   - 禁用 dev 账户
   - 关闭 SSH 密码认证

2. **证据保全**：
   - 复制所有日志到安全位置
   - 制作 Docker 容器快照
   - 记录当前时间戳

3. **通知**：撰写简短的事故通告
