# TITLE: 初始入侵 — 识别攻击入口
# STEP: 5
# MINUTES: 12

### WHY

找到初始入侵点（Initial Access）是遏制攻击的关键。不问"他们怎么进来的"，就无法堵住入口。

**常见初始入侵向量**：
- 弱密码/默认密码
- 未修补的漏洞
- 钓鱼邮件
- 暴露的服务

   - 然后用 `student/Student123` 成功登录（10:04:52）

2. **攻击者用的凭证是什么？**

3. **攻击者在系统上做了什么？**

   - 尝试登录 Web 应用（10:07:20）
   - 触发了数据导出（10:09:44）
