# STEP: 1
# MINUTES: 8

### WHY

资产侦察（Reconnaissance）是网络安全的**第一步**。无论是攻击者还是防御者，都需要先知道"目标有什么"。

攻击者用它来：
- 发现开放的端口和服务
- 识别操作系统和软件版本
- 找到可能存在的漏洞

防御者用它来：
- 了解自己的暴露面
- 发现意外的开放端口
- 建立资产清单

**常见的侦察技术**：
- 端口扫描：Nmap、Masscan
- 服务探测：识别端口上运行的具体软件
- OS 指纹识别：判断目标操作系统
- Web 目录扫描：发现隐藏的路径

**本实验中你会**：
- 确认实验边界为本地 127.0.0.1
- 用 Nmap 扫描本地的 Docker 服务
- 构建一张完整的资产表

⚠️ **重要提醒**：本实验所有扫描仅限 127.0.0.1，绝对不要扫描外部网络或他人机器！
