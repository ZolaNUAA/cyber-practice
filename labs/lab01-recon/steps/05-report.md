# TITLE: 报告 — 构建资产表
# STEP: 5
# MINUTES: 12

### WHY

资产表是安全工作的基础文档。一个好的资产表能让你一眼看清：
- 哪些服务在运行
- 它们的风险等级
- 需要优先加固的目标

在企业环境中，资产表通常用 CMDB（配置管理数据库）维护，定期自动更新。

### DO

创建资产表文件：
```
nano ~/cyber-practice/reports/lab01-asset-table.md
```

**资产表格式**（至少包含以下列）：

| 端口 | 服务 | 版本 | 用途 | 风险等级 | 风险说明 |
|------|------|------|------|----------|----------|
| 2222 | SSH | OpenSSH | 远程管理 | 中 | 弱密码 Student123 |
| 8082 | HTTP | nginx | Web服务 | 中 | backup目录暴露 |
| 3000 | HTTP | Node.js | Juice Shop | 高 | 教学靶场，含多个漏洞 |

**额外内容**：
1. 至少 3 条风险观察
2. 实验室边界声明（一句话）
3. Nmap 扫描截图或命令输出
