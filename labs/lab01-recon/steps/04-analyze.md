# TITLE: 分析 — 识别服务与评估风险
# STEP: 4
# MINUTES: 10

### WHY

端口扫描只是第一步。真正的价值在于**解读扫描结果**：

- 看到一个开放的 SSH 端口（2222）→ 可能存在弱密码风险
- 看到 HTTP 服务（8082, 8086）→ 需要检查 Web 应用安全
- 看到数据库端口 → 可能存在 SQL 注入或未授权访问

每个开放端口都是一个**潜在的攻击面**。防御者的目标不是关闭所有端口，而是确保每个开放的服务都经过加固。

### DO

1. 用浏览器访问每个 HTTP 服务：
   - http://127.0.0.1:8082
   - http://127.0.0.1:8086
   - http://127.0.0.1:3000
   - http://127.0.0.1:8080/WebGoat

2. 用 curl 查看 HTTP 响应头：
```
curl -I http://127.0.0.1:8082/
```

3. 尝试 SSH 连接：
```
ssh student@127.0.0.1 -p 2222
# 密码: Student123
```

4. 对每个服务写下：
   - 它是什么？（Web/SSH/API）
   - 它应该暴露吗？
   - 有哪些可能的攻击面？

- [ ] 对每个服务有了风险评估
