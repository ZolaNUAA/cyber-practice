# TITLE: 环境准备 — 确认实验边界
# STEP: 2
# MINUTES: 5

### WHY

所有安全实验必须在**受控环境**中进行。本课程的边界是：

- **IP 范围**：仅限 `127.0.0.1`（本地回环地址）
- **端口范围**：3000, 8080, 8082, 8086, 8089, 2222
- **禁止**：扫描校园网、同学机器、互联网主机

`127.0.0.1` 是一个特殊地址——它指向你自己的机器。任何发送到 127.0.0.1 的数据都不会离开你的电脑。

### DO

1. 启动实验环境：
```
cd ~/cyber-practice
./reset-lab.sh lab01
```

2. 确认 127.0.0.1 就是本地：
```
ip addr show lo
```
你应该看到 `inet 127.0.0.1/8`。

3. 查看当前运行的 Docker 容器：
```
docker ps --format "table {{.Names}}	{{.Ports}}"
```

### CHECK

- 是否看到至少 3 个 Docker 容器在运行？
- 它们的端口是否都在 127.0.0.1 上？
