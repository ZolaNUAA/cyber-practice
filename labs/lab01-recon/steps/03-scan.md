# TITLE: 扫描 — 用 Nmap 发现端口和服务
# STEP: 3
# MINUTES: 12

### WHY

Nmap 是行业标准的端口扫描工具。它的工作原理是向目标端口发送网络包，根据响应判断端口状态：

- **open**：有服务在监听
- **closed**：端口可达但无服务
- **filtered**：被防火墙阻止

`-sV` 参数不仅能发现开放端口，还会**探测服务名称和版本**——这是资产侦察的核心能力。

### DO

1. 对预期的端口范围执行服务版本扫描：
```
nmap -sV -p 3000,8080,8082,8086,8089,2222 127.0.0.1
```

2. 观察输出，记录每个端口的：
   - 端口号
   - 服务名称（如 http, ssh）
   - 版本信息（如 nginx 1.25, OpenSSH 9.x）

3. 尝试更详细的扫描（可选）：
```
nmap -sV -sC -p 3000,8080,8082,8086,8089,2222 127.0.0.1
```
`-sC` 运行默认的 NSE 脚本，可能获取更多信息。

### CHECK

- 你能识别出至少 4 个不同的服务吗？
- 是否有服务版本让你觉得可能存在已知漏洞？
