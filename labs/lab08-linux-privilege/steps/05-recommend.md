# TITLE: 建议 — 最小权限改进方案
# STEP: 5
# MINUTES: 12

### WHY

基于前面的发现，提出具体改进建议：

**文件权限改进**：
- `app.env` 的权限应为 0600，且所有者为应用用户
- 备份目录不应该被普通用户读取

**sudo 规则改进**：
- 限制参数：使用固定参数而非任意参数
- 考虑使用 `sudo` 的 `Cmnd_Alias` 和详细规范
- 如果可能，用专用的 API/脚本替代 sudo

**额外建议**：
- 定期审计 sudo 规则和文件权限
- 使用 SELinux/AppArmor 增加额外限制
- 对敏感操作增加审计日志
