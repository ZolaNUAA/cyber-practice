# TITLE: 报告 — 撰写实验报告
# STEP: 7
# MINUTES: 15

### WHY

在真实的网络安全工作中，**写报告和做攻击同样重要**。一个漏洞如果不能被清晰地描述和传达，就无法被有效修复。

好的安全报告应该包含：
- **做了什么** — 攻击步骤和证据
- **为什么能成功** — 漏洞原理
- **影响是什么** — 风险评级
- **怎么修** — 可执行的修复建议

### DO

创建你的实验报告文件：

\`\`\`
nano ~/cyber-practice/reports/lab04-report.md
\`\`\`

报告应包含以下内容：

1. **实验信息**：实验编号、日期、学生姓名
2. **攻击证据**：Burp Suite 截图或 curl 输出
3. **漏洞参数说明**：哪个参数接收了注入 payload，为什么危险
4. **攻击原理**：用你自己的话解释 SQL 注入的工作方式
5. **修复方案**：至少 3 条具体的修复建议（参考步骤 6）
6. **心得体会**：本次实验你学到的最重要的东西

### CHECK

报告是否包含以上 6 项内容？
