### WHY

修复命令注入有多个层次：

**银弹：不用 Shell**
```python
subprocess.run(["ping", "-c", "1", target], shell=False)
```

**纵深防御**：
1. **参数数组**（不用 Shell）— 最核心
2. **输入白名单** — 只允许 IP 地址格式
3. **最小权限** — 应用以低权限用户运行
4. **超时限制** — `timeout=5`，防止资源耗尽
5. **容器隔离** — 即使被注入，攻击面也有限
