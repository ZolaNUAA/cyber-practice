# 学生修复提示卡

本考试考察 Linux/Nginx 服务配置加固。优先修改：

```text
services/exam-gateway/default.conf
```

修改后重启：

```bash
docker compose -f docker-compose.yml restart exam-gateway
```

下面是方向提示，不是完整答案。目标是修复配置根因，而不是修改 Python 应用。

## 1. 备份文件暴露

问题特征：备份目录或配置备份文件可以被浏览器直接访问。

配置加固方向：

- 对 `/backup/` 返回 `403`
- 或移除对备份目录的 Web 暴露
- 不要只隐藏首页链接，直接访问文件也必须失败

## 2. 目录索引暴露

问题特征：访问目录路径时，Nginx 自动列出目录下的文件名。

配置加固方向：

- 关闭 `autoindex`
- 或对敏感目录返回 `403`
- 不要让访问者通过目录列表发现内部文件

## 3. 管理路径暴露

问题特征：`/admin/` 下的管理状态、调试信息或内部接口对所有人开放。

配置加固方向：

- 对 `/admin/` 返回 `403`
- 或只允许本机/指定网段访问
- 普通用户从浏览器直接访问管理路径应失败

## 4. 上传目录主动内容暴露

问题特征：上传目录中的 `.html`、`.js`、`.svg` 等主动内容能被浏览器直接访问和执行。

配置加固方向：

- 禁止访问上传目录中的主动内容扩展名
- 或让上传目录只以下载形式返回
- 至少应阻断 `/uploads/*.html` 这类访问
